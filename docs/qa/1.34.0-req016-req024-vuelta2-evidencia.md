## 6 · Los scripts de sonda, para re-derivar sin preguntar

Viven en el scratchpad de la sesión (efímero) y se reproducen aquí en lo esencial. Los cuatro
comparten el mismo invocador de la puerta, que es el del banco (`ver40` de
`40-ausencia-que-abre-2-migracion-y-punteros.sh:141-160`): la edición viaja pequeña y el guardián

```bash
ver() {   # <hooks-dir> <exige true|false> <cuerpo-cabecera> -> DENY|ALLOW
  printf '%s\n' "$MANIFIESTO_BASE" | jq ".campos.ausencia_exige = $2" > "$P/.arnes/config.json"
  { printf '# REQ-900\nEstado: en-revisión\n%s\n\n## Historia\nx.\n' "$3"; } > "$P/requirements/REQ-900.md"
  o="$(CLAUDE_PROJECT_DIR="$P" jq -n --arg fp "$P/requirements/REQ-900.md" \
        '{hook_event_name:"PreToolUse",tool_name:"Edit",cwd:env.CLAUDE_PROJECT_DIR,
          tool_input:{file_path:$fp,old_string:"Estado: en-revisión",new_string:"Estado: completado"}}' \
      | CLAUDE_PROJECT_DIR="$P" "$1/guard-completado.sh" 2>/dev/null)"
  case "$o" in *'"permissionDecision":"deny"'*|*'"permissionDecision": "deny"'*) printf DENY;; *) printf ALLOW;; esac
}
# La mutación, con el valor por ENTORNO y su efecto VERIFICADO:
MUT="gobierna:aprobado" perl -0pi -e 's/(\$ARNES_CLAVE_SEG\|)[^|"]*/$1 . $ENV{MUT}/ge' "$W/hooks/lib.sh"
```
